# PaperJay brand

The mark is a **P** and a **J** hooked into each other, slanted, with a blue jay's crest over the P:
the P's round top is the jay's head.

| File | Use |
|---|---|
| [`../../paperjay/static/icons/icon.svg`](../../paperjay/static/icons/icon.svg) | the app icon (dark tile) |
| [`../../paperjay/static/icons/icon-small.svg`](../../paperjay/static/icons/icon-small.svg) | the app icon at tiny sizes (browser tab): bolder strokes |
| [`icon-light.svg`](icon-light.svg) | the app icon on a light tile |
| [`mark-on-dark.svg`](mark-on-dark.svg) / [`mark-on-light.svg`](mark-on-light.svg) | the mark alone, for dark / light backgrounds |
| [`mark-black.svg`](mark-black.svg) / [`mark-white.svg`](mark-white.svg) | one colour (print, stamps, watermarks) |
| [`lockup-on-dark.svg`](lockup-on-dark.svg) / [`lockup-on-light.svg`](lockup-on-light.svg) | mark + wordmark |

**Colours**: blue `#6ea8fe` on dark backgrounds, `#2f6fde` on light ones (the app's accent colours);
white `#f4f4f5` / near-black `#18181b` for the P and "Paper".

**Wordmark**: "PaperJay" in [Outfit](https://github.com/Outfitio/Outfit-Fonts) SemiBold (SIL Open Font
License 1.1), converted to outlines, so no font is needed to show it. "Paper" takes the P's colour, "Jay" the
blue.

**Spacing**: keep clear space around the mark of at least the width of the J's stroke × 2; don't stretch,
recolour beyond the pairs above, or remove the crest. Under 32 px use `icon-small.svg`.

The PNG app icons in `paperjay/static/icons/` are rendered from the SVGs by `scripts/make_icons.py`.
